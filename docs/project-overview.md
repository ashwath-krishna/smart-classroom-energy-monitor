# Project Overview

## Project title
Smart Classroom Energy Monitor

## Project description
The project proposes a classroom occupancy-monitoring concept using an ESP32 and two types of sensors: mmWave radar as the primary occupancy sensor and PIR as a secondary sensor. Sensor readings are intended to be sent over Wi-Fi to a Python dashboard.

The dashboard is proposed to display sensor states, the combined occupancy state, inactivity duration, estimated energy use, and potential savings.

## Problem being addressed
Classroom lights and fans may remain ON when a room is empty. A reliable occupancy decision could help identify opportunities to reduce avoidable energy use. The project focuses on exploring whether combining mmWave and PIR sensing can reduce false-vacancy decisions compared with relying on PIR alone.

## Proposed contribution
The intended student-project contribution is a low-cost prototype concept, a measured comparison of PIR-only and dual-sensor occupancy decisions, conservative vacancy logic, and transparent energy estimates.

## Status
The available project material describes a proposal and planned evaluation. It does not provide completed prototype evidence, experimental results, or validation data.
